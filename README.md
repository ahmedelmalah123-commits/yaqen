# 🕋 منصة اليقين | Yaqeen Platform
> **مشروع تخرج متكامل - منصة إسلامية صوتية ومرئية تفاعلية مدعومة بالذكاء الاصطناعي**

منصة **اليقين** هي تطبيق ويب حديث متكامل مصمم لتقديم محتوى إسلامي صوتي ومرئي بجودة عالية، مع إدماج تقنيات الذكاء الاصطناعي التفاعلية لتوفير تجربة مستخدم روحانية وتعليمية مميزة.

---

## 📸 نظرة عامة على المشروع (Project Overview)
تم تصميم المنصة لتكون مرجعاً سهلاً وتفاعلياً للمستخدمين للاستماع للقرآن الكريم، تدبر السيرة النبوية، الرقية الشرعية، والتفاعل مع مرشد ذكي يجيب على أسئلتهم الدينية والثقافية.

### 🌟 الميزات الرئيسية (Key Features)
1. **🎧 مشغل الصوتيات المتقدم (Advanced Audio Player):** مشغل مدمج وسلس يدعم تشغيل السور والأذكار، ويتيح التحكم الكامل في التشغيل مع ميزة التخزين المؤقت (Offline Caching) لضمان العمل بدون إنترنت.
2. **🤖 المساعد الذكي "الشيخ عم بركة" (Amm Baraka Assistant):** مساعد ديني تعليمي تفاعلي مدعوم بنموذج **Google Gemini 3.5 Flash**، مصمم بشخصية حكيمة وودودة بالعامية المهذبة للإجابة عن أسئلة السيرة، الفقه، والقرآن.
3. **🛡️ محرك الردود المحلي الاحتياطي (Local Fallback Engine):** محرك مدمج يضمن استمرارية عمل الشات وتقديم ردود ذكية مناسبة في حال انقطاع الاتصال بالإنترنت أو عدم تهيئة مفاتيح الـ API.
4. **🎨 تصميم واجهة مميز (Premium RTL UI/UX):** واجهة متوافقة بالكامل مع اللغات التي تكتب من اليمين إلى اليسار (RTL)، تدعم الوضع الداكن والفاتح (Dark/Light Modes)، مع مؤثرات حركية ناعمة وخلفيات زخرفية إسلامية متحركة.
5. **📊 لوحة تحكم وإدارة خادم (Serverless Backend):** استخدام Netlify Functions لتأمين الطلبات للذكاء الاصطناعي وحماية مفاتيح الوصول.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية (Frontend):** React (Vite), TypeScript, Tailwind CSS, Framer Motion (للحركات التفاعلية).
* **الذكاء الاصطناعي (AI Integration):** Google Generative AI SDK (نموذج Gemini 3.5 Flash).
* **قاعدة البيانات والخدمات (Backend/Database):** Supabase (لإدارة المستخدمين والبيانات الحية).
* **وظائف الخادم (Serverless functions):** Netlify Functions لتوفير خدمات آمنة بدون خادم كامل.

## 🚀 طريقة التشغيل والتهيئة المحلية (Installation & Setup)

### المتطلبات الأساسية (Prerequisites)
تأكد من تثبيت بيئة عمل [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### خطوات التشغيل:

1. **تثبيت الحزم البرمجية (Install Dependencies):**
   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة (Environment Variables):**
   قم بإنشاء ملف باسم `.env.local` في المجلد الرئيسي للمشروع وضع فيه القيم التالية:
   ```env
   VITE_GEMINI_API_KEY=مفتاح_جوجل_جيميني_الخاص_بك
   VITE_SUPABASE_URL=رابط_مشروع_سوبابيس
   VITE_SUPABASE_ANON_KEY=مفتاح_سوبابيس_العام
   ```

3. **تشغيل خادم التطوير المحلي (Run Development Server):**
   ```bash
   npm run dev
   ```
   سيتم تشغيل التطبيق محلياً على الرابط: `http://localhost:5173/`

4. **بناء نسخة الإنتاج (Build for Production):**
   ```bash
   npm run build
   ```
   سيتم توليد ملفات جاهزة للنشر الفوري داخل مجلد `dist`.
